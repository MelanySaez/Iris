# SPHEREx DR1 All-Sky Cube fallback

Objective: when IRSA TAP discovery is unavailable and the indexed S3 L2 fallback has no products, build job cutouts/mosaics from the DR1 HiPS spectral cube tiles on S3, tell the user exactly what happened (including the lack of temporal information), and make the plate view work with both sources.
Branch: feat/spherex-s3-poc. Delivery: feature-branch-chain, local work-unit commits only (no push/PR). Runner: `uv run --no-sync pytest` (apps/server), `vitest` (apps/web).

## Specs

S1. "requiero que implementes esta solucion en esta rama, esta solucion seria un fallback al metodo irsa tap: coutouts, mosaicos, retroalimentacion al usuario para que comprenda que sucede,ajustar el apartado de plate para que funcione con ambos metodos". Fallback order: IRSA TAP → indexed S3 L2 (existing, keeps temporal epochs) → DR1 cube on S3. Cube regions of 1–180 arcmin, one or several HEALPix order-5 tiles reprojected onto one north-up TAN grid (cutout and mosaic). Existing IRSA/L2 behavior unchanged.
S2. "la retroalimentacion al usuario debe avisar que este fallback carece de informacion temporal". Job events, discovery summary, animation reason and the plate UI state that the cube combines all DR1 observations (date range from the tile) into one image; epochs, timeline comparison and animation are unavailable.
S3. "unicamente necesitamos los campos de IMAGE,FLAGS Y WCS-WAVE y opcionalmente el NHITS" "Pensamos en cargar x canal especifico y no todos de golpe para los campos descritos". Read only the requested channel plane, only the needed row span, per HDU, with HTTP range requests; never download a whole tile. Cube has no VARIANCE: variance frames are not produced and the UI says so. Wavelength comes from the cube channel table (nominal per channel), never presented as calibrated.

S4. "si falló y cargó el último, que utilice ese directamente y ya". Loading another product (e.g. FLAGS) for a region whose IRSA TAP discovery just failed must not retry TAP and its fallbacks again; reuse the provider that served the region (bounded TTL) and the already-built cube cutouts.
S5. "se quedó pegado en intento uno y no pasa de ahí" "tampoco hay una barra progresiva que indique cuanto tiempo falta de ese intento" "El usuario tiene que estar enterado del progreso de todo en TODO MOMENTO". Every discovery attempt and every fallback/cube read reports live progress: elapsed vs. its time budget, attempt n of m, and per-channel/tile progress.
S6. "La elección de colores de letra y fondos está fatal, no se entiende bien el texto" (red fallback banner, "Data source and service status", third capture popups). Readable contrast (WCAG AA) for the fallback notice, provider trace and stage warnings.
S7. "EL banner rojo de error debería de tener una X" "El banner y el popup que salió se deberían de poder quitar, alguna X sería de mucha ayuda". Fallback notice and stage warning popups are dismissible.
S8. "dentro del mismo cuadro skeleton que está cargando debería de aparecer la barra progresiva" "podríamos mover el status de arriba a la derecha para que vaya ahí dentro directamente (aplica para todos los casos, sin importar el estado)". Progress bar and job status live inside the plate stage for every state; the header status pill is removed.
S9. "sigue implementando los pendientes que tenías del navegador y otros". Parallel tile reads; browser verification of the plate; cube-specific plate copy (title, units, LVF/flag notes) so the cube is not described as Level-2/WCS-WAVE.

S10. "necesito que quede retractil las 2 sidebars que aparecen en la pestaña de plate". Plate record (left) and spectral rail (right) collapse/expand independently; choice remembered per browser. Correction: "necesito que la opcion del retractil aparezca sobre los laterales y no sobre el elemento de el medio" — each toggle lives on its sidebar; a collapsed sidebar is a 28px strip holding only its toggle.

Assumptions (verified 2026-11-15 on tile Npix7416): S3 key `dr1/hips5_cube/hips_20261026/Norder5/Dir{(n//10000)*10000}/Npix{n}_cube.fits`; IMAGE/NHITS/FLAGS uncompressed 512×512×102; channel plane = 1 MiB contiguous; `BLANKCH` lists all-NaN planes.
