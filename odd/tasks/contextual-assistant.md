# Contextual assistant

Objective: a contextual chatbot (any OpenAI-compatible model) that lives behind an icon in the bottom-right corner of the app, can inspect and drive the interface through tool calling, is protected by guardrails, logs every action and model call, and caches equal or similar requests.
Branch: `feat/contextual-assistant` · Delivery: ask-on-risk · Runners: `uv run pytest -q` (server, `.env` sourced), `pnpm exec vitest run` (web).

## Specs

- **S1** — Placement: "una especie de chatbot contextual que va a vivir con su icono en la parte inferior derecha de la aplicación". A launcher icon fixed bottom-right opens a chat panel on every workspace.
- **S2** — System prompt: "Quiero que contenga un system prompt que sea como la instrucción general para nuestro proyecto". A frozen server-side system prompt describing Planet X (SPHEREx DR1 explorer: Sky, Plate, Spectral Lab, Records) and how the assistant behaves.
- **S3** — Tool calling over the UI: "que permita tener un tool calling para poder hacer cambios sobre la interfaz y poder consultar y movernos a lo largo de la interfaz a partir de las instrucciones que se den". Tools to read UI state, search the catalog, list saved selections, navigate between workspaces, move the Sky map to a region, change channel and colour mode.
- **S4** — Guardrails: "necesito que tenga guardrails para proteger y mitigar problemas como el prompt injection". Untrusted content (UI context, tool results, user-named records) is delimited as data; tool inputs are validated server- and client-side against an allowlist and ranges; prompt-leak canary; input length/turn limits; loop cap; refusals handled; costly or destructive actions are not exposed to the model (no job confirmation, no rename/delete).
- **S5** — Traceability logs: "necesito que me deje un sistema de logs en el que muestre pues todos los movimientos, todos los usos del modelo y demás, para poder tenerlos de referencia". Append-only log of every request, model call (model, tokens, cache usage, latency, stop reason), tool call, UI action, cache hit, guardrail event and error, readable through the API and shown in the chat panel.
- **S6** — Response cache: "necesito que maneje caché para cuando se realicen solicitudes iguales, poder consultar en este espacio sin necesidad de tener que hacer la consulta completa nuevamente" / "también debe tener sistema para utilizar caché en el caso de que existan solicitudes iguales o similares, para evitar tener que hacer la consulta directa nuevamente al modelo vía API". Equal (normalized) and similar (token-overlap) requests in the same context are answered from cache, replaying the stored UI actions; Provider-supported prompt caching can reuse the stable prefix on cache misses.
- **S7** — API key: "Puedes colocar en el environment.example la línea para definir la API key que se va a utilizar del modelo del chatbot". `ASSISTANT_API_KEY`, `ASSISTANT_MODEL` and `ASSISTANT_BASE_URL` (plus optional limits) in `apps/server/.env.example`.
- **S8** — Provider: "Simplemente quiero que deje el espacio para yo poder definir la API key del modelo que sea de mi preferencia. De hecho, prefiero que se utilicen aquellos modelos que sean compatibles con SDK de OpenAI. No necesito que sean de Anthropic". The assistant uses the official OpenAI Python SDK (Chat Completions with tools) against any OpenAI-compatible endpoint: `ASSISTANT_API_KEY`, `ASSISTANT_MODEL` (no default) and optional `ASSISTANT_BASE_URL`. No Anthropic dependency. Without key or model the assistant answers 503 and the rest of the app keeps working.

- **S9** — Markdown: "necesito que ahora la salida que da el modelo tenga bien renderizado su md, para que tenga mejor estilo". Render assistant replies as styled Markdown; retain plain user input and original history.
- **S10** — Credits: "me gustaria que se coloque por ejemplo al explicar la app o al preguntar por sus autores digan los nombres que son Aarón Dali López Fortich, Melany Saez Acuña, Gabriel Mantilla Clavijo y Juan Perez Navarro mostrando a lado de cada uno los links a los profiles de github (puedes rescatar los links del profile del repo ) y mencionar ademas el repo de la app en si".
- **S11** — Blocking: "necesito que se mitigue o se bloqueen la parte de patrones como ignora las instrucciones o toca o modifica,altera o borra codigo propio de la aplicacion". Block detected user requests before cache, model and tool calls; preserve legitimate app assistance.
- **S12** — Integration: "necesito entonces mirar que ya este completo la funcionalidad del chatbot y pues luego de eso mergear a main y mandar a remoto, antes de todo traete los cambios del remoto para mirar que sea compatible y existan conflictos".
